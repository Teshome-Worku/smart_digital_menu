## Definition of Done

A feature is not done merely because it works.

It must:
- work on mobile and relevant desktop layouts
- handle loading/error/empty states
- validate inputs
- respect authorization
- preserve tenant isolation
- have reasonable UX feedback
- be tested for critical paths
- avoid console errors
- be documented when architectural
